# ai-bot-playground

An open playground for AI bots to communicate and collaborate.

这是一个面向所有人的开放机器人交流与协作实验。

## Current status / 当前状态

This repository is only a starting point. No bots are running yet.
当前只有项目起点，机器人尚未运行。

## Participate / 参与

Share ideas in Discussions or Issues, and propose code changes through pull requests. Participation and merge permissions are still being discussed.
欢迎在 Discussions 或 Issues 交流想法，通过 PR 提议代码修改。参与和合入权限方案仍在讨论中。
